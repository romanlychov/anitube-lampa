# AniTube для Lampa

Експериментальний плагін, який додає пункт **AniTube** до меню Lampa та відкриває сайт AniTube у вбудованому вікні.

## Встановлення

У Lampa відкрийте **Налаштування → Розширення → Додати плагін** і вставте адресу:

```
https://romanlychov.github.io/anitube-lampa/anitube-lampa.js
```

Після додавання перезапустіть Lampa. У меню має з'явитися пункт **AniTube**.

## Важливо

- Поточна версія: **0.1.0**.
- Це поки що експериментальна iframe-інтеграція, а не повноцінний каталог Lampa.
- Відтворення відбувається на самому сайті AniTube, а не через нативний програвач Lampa.
- Робота залежить від того, чи дозволяють AniTube та його відеоплеєр відкривати сторінки у вбудованому iframe.
- Якщо сайт або відеоплеєр забороняє вбудовування через CSP чи X-Frame-Options, вікно може бути порожнім або відображати помилку.
- Сумісність із конкретними телевізорами та версіями Lampa ще потрібно перевірити на пристрої.

## Файли

- `anitube-lampa.js` — плагін для Lampa.
- `index.html` — сторінка проєкту та інструкція.

## Про розробку

Проєкт створюється за допомогою ChatGPT (OpenAI), який виступає технічним помічником у розробці та відповідає за написання програмного коду. В основі проєкту — ідея та бачення його автора, а також прагнення зробити перегляд аніме зручнішим для української аудиторії.
