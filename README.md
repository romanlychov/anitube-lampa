# AniTube для Lampa

Експериментальний плагін для поступової інтеграції каталогу AniTube у Lampa.

## Встановлення

У Lampa відкрийте **Налаштування → Розширення → Додати плагін** і вставте адресу:

```
https://romanlychov.github.io/anitube-lampa/anitube-lampa.js
```

Після додавання перезапустіть Lampa. У меню має з'явитися пункт **AniTube**.

## Версії

### 0.2.6 — поточна

Перероблено екрани каталогу та деталей:
- Екрани переведені на штатний `Lampa.Scroll`; прокручування має слідувати за фокусом пульта.
- Виправлено оновлення списку фокусованих елементів після асинхронного завантаження каталогу.
- Додано реєстрацію відеоджерела AniTube через `Lampa.Manifest.plugins`, щоб відкривати пошук AniTube з контекстного меню картки.
- Прибрано кнопку, яка просто відкривала сторінку сайту у браузері Lampa.
- Додано спробу розібрати посилання FenixPlay, отримати дані серії через playback API, показати вибір озвучення та передати HLS-посилання штатному `Lampa.Player.play()`.
- Якщо токен FenixPlay не знайдено або API недоступне, плагін показує конкретну помилку замість удаваного запуску браузерної сторінки.

**Важливо:** інтеграція FenixPlay поки експериментальна. У HAR підтверджено, що API серії вимагає тимчасовий заголовок `X-Fenix-Playback`, а медіаплейлисти використовують окремий короткоживучий токен доступу. Автоматичне отримання всіх потрібних токенів і сумісність окремих HLS-аудіо/відеопотоків зі штатним програвачем ще не підтверджені. Потрібен тест на телевізорі.

## Перевірка

Версія 0.2.6 має перевірений синтаксис JavaScript, але не перевірена на реальному телевізорі. HTTP 200 означає лише, що Lampa отримала JavaScript-файл; це не підтверджує роботу каталогу, токенів або відтворення.

## Файли

## Про розробку

Проєкт створюється за допомогою ChatGPT (OpenAI), який виступає технічним помічником у розробці та відповідає за написання програмного коду. В основі проєкту — ідея та бачення його автора, а також прагнення зробити перегляд аніме зручнішим для української аудиторії.
