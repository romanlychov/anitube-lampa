# AniTube для Lampa

Експериментальний плагін для поступової інтеграції каталогу AniTube у Lampa.

## Встановлення

У Lampa відкрийте **Налаштування → Розширення → Додати плагін** і вставте адресу:

```
https://romanlychov.github.io/anitube-lampa/anitube-lampa.js
```

Після додавання перезапустіть Lampa. У меню має з'явитися пункт **AniTube**.

## Версії

### 0.2.5 — поточна

Виправлення переходу пультом до карток каталогу:
- Після завершення завантаження сторінки список навігації Lampa оновлюється з урахуванням щойно доданих карток.
- Початковий фокус повертається на перший елемент екрана, після чого можна рухатися вниз через пошук до карток.
- Оновлення списку виконується також після помилки завантаження.

Синтаксис JavaScript перевірено. Поведінку на телевізорі потрібно перевірити.

### 0.2.4

Виправлення керування пультом:
- Додано обробники напрямків «ліворуч», «праворуч», «угору» та «вниз» для екранів каталогу й деталей.
- Навігація використовує штатні `Navigator.canmove()` і `Navigator.move()`; на межах списку ліворуч і вгору повертає керування меню та шапці Lampa.

Синтаксис JavaScript перевірено. Реальне керування пультом потребує повторного тесту на телевізорі.

### 0.2.3

Виправлення зупинки каталогу під час розбору зображень:
- Виправлено регулярний вираз для пошуку CSS `background-image`, який спричиняв `SyntaxError: Unterminated group` на телевізорі.
- Виправлено розділення значень `srcset` за пробілами.

Це виправлення усуває конкретну синтаксичну помилку, виявлену під час запуску каталогу. Роботу каталогу та керування пультом потрібно повторно перевірити на телевізорі.

### 0.2.2

Виправлення помилки запуску екранів та керування:
- Додано обов'язковий метод `start()` для екранів каталогу й деталей — попередня версія не проходила етап запуску Activity у Lampa.
- Додано явне передавання списку елементів у систему фокуса Lampa та початкове встановлення фокуса.
- Вибір картки підтримує як подію пульта `hover:enter`, так і натискання.
- Покращено пошук постерів у HTML: перевіряються кілька lazy-loading атрибутів, `srcset`, назви класів зображень і фонові зображення.

Зміни усувають виявлену в коді причину помилки `this.component.start is not a function`, але ще не перевірені на телевізорі. Завантаження кожного постера також потребує практичної перевірки.

### 0.2.0

- Замість порожнього iframe відкривається окремий екран каталогу всередині Lampa.
- Список аніме завантажується з головної сторінки AniTube.
- Додано пошук через пошукову форму сайту.
- Додано перехід на сторінку вибраного тайтлу та кнопку відкриття його сторінки на AniTube.
- Додано обробку помилок завантаження та спробу визначення наступної сторінки каталогу.

**Що ще не реалізовано:** автоматичне розбирання сезонів і серій, вибір озвучення всередині Lampa та запуск відео через рідний програвач Lampa. Відкриття сторінки AniTube з екрана деталей може залежати від підтримки зовнішнього браузера конкретною збіркою Lampa.

### 0.1.0

Початкова експериментальна версія з відкриттям AniTube у вбудованому iframe. На телевізорі користувача iframe показав білий екран, тому цей підхід замінено власним екраном каталогу.

## Перевірка

Версія 0.2.5 опублікована для наступного практичного тестування в Lampa. Код не перевірений на реальному телевізорі. Статус завантаження плагіна HTTP 200 означає лише, що Lampa отримала JavaScript-файл; він не підтверджує роботу каталогу, постерів чи відтворення.

## Файли

- `anitube-lampa.js` — плагін для Lampa.
- `index.html` — сторінка проєкту.

## Про розробку

Проєкт створюється за допомогою ChatGPT (OpenAI), який виступає технічним помічником у розробці та відповідає за написання програмного коду. В основі проєкту — ідея та бачення його автора, а також прагнення зробити перегляд аніме зручнішим для української аудиторії.
