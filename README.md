# AniTube для Lampa

Експериментальний плагін для поступової інтеграції каталогу AniTube у Lampa.

## Встановлення

У Lampa відкрийте **Налаштування → Розширення → Додати плагін** і вставте адресу:

```
https://romanlychov.github.io/anitube-lampa/anitube-lampa.js
```

Після додавання перезапустіть Lampa. У меню має з'явитися пункт **AniTube**.

## Версії

### 0.2.1 — поточна

Проміжне виправлення керування з пульта:
- Додано фокусовані елементи керування для пошуку та оновлення.
- Кнопки реагують на події пульта Lampa (`hover:enter`) і звичайне натискання.
- Поле пошуку викликає екранний редактор введення Lampa, якщо він доступний.
- Додано додаткові варіанти адреси постерів із lazy-loading атрибутів.

Ці зміни ще потребують перевірки на телевізорі.

### 0.2.0

- Замість порожнього iframe відкривається окремий екран каталогу всередині Lampa.
- Список аніме завантажується з головної сторінки AniTube.
- Додано пошук через пошукову форму сайту.
- Додано перехід на сторінку вибраного тайтлу та кнопку відкриття його сторінки на AniTube.
- Додано обробку помилок завантаження та спробу визначення наступної сторінки каталогу.

**Що ще не реалізовано:** автоматичне розбирання сезонів і серій, вибір озвучення всередині Lampa та запуск відео через рідний програвач Lampa. Відкриття сторінки AniTube з екрана деталей може залежати від підтримки зовнішнього браузера конкретною збіркою Lampa.

### 0.1.0

Початкова експериментальна версія з відкриттям AniTube у вбудованому iframe. На телевізорі користувача iframe показав білий екран, тому цей підхід замінено власним екраном каталогу.

## Перевірка

Версія 0.2.0 опублікована для практичного тестування в Lampa. Її ще не перевірено на реальному телевізорі. Статус завантаження плагіна HTTP 200 означає лише, що Lampa отримала JavaScript-файл; він не підтверджує роботу каталогу чи відтворення.

## Файли

- `anitube-lampa.js` — плагін для Lampa.
- `index.html` — сторінка проєкту.

## Про розробку

Проєкт створюється за допомогою ChatGPT (OpenAI), який виступає технічним помічником у розробці та відповідає за написання програмного коду. В основі проєкту — ідея та бачення його автора, а також прагнення зробити перегляд аніме зручнішим для української аудиторії.
