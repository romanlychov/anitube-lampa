# AniTube для Lampa

Експериментальний плагін для поступової інтеграції каталогу AniTube у Lampa.

## Встановлення

У Lampa відкрийте **Налаштування → Розширення → Додати плагін** і вставте адресу:

```
https://romanlychov.github.io/anitube-lampa/anitube-lampa.js
```

Після додавання перезапустіть Lampa. У меню має з'явитися пункт **AniTube**.

## Версії

### 0.2.20 — поточна

- Для кожної картки без постера окремо завантажується сторінка відповідного тайтлу та шукається `og:image`, `twitter:image` або основне зображення статті. Одночасно виконуються не більше трьох таких запитів.
- Прибрано неактивні кнопки вибору серії, озвучення, субтитрів і відтворення. Нижній блок тепер містить оригінальну сторінку AniTube з її власним плеєром; пов'язані сезони залишаються окремими посиланнями.
- Іконку замінено на мінімалістичний контурний символ екрана з кнопкою відтворення у стилі Lampa.

**Важливо:** HTTP 403 на зовнішньому запиті плейлиста не усунуто. Плагін більше не імітує керування серіями/озвученням без отриманих даних. Працездатність iframe та керування ним пультом треба перевірити на телевізорі.

- Каталог більше не показує картки одразу після розбору HTML: спершу перевіряються адреси постерів, зображення завантажуються й декодуються (до 6 одночасних завантажень), після чого відображається готовий список. Якщо картинка не завантажилася, картка лишається без постера.
- Парсер постерів став суворішим: бере зображення лише з елементів, прив'язаних до конкретного посилання або явного контейнера постера; повторні однакові URL відкидаються, щоб один випадковий постер не розмножувався на весь каталог.
- На сторінці тайтлу додано блок керування: сезон, серія, озвучення, субтитри та запуск відтворення. Озвучення й субтитри заповнюються лише тоді, коли FenixPlay реально повернув відповідні дані.
- Якщо знайдено посилання FenixPlay, сторінка плеєра може відкриватися безпосередньо у вбудованій області. Це запасний шлях: у разі обмеження CORS власні списки озвучення/субтитрів можуть лишитися недоступними, тоді їх слід вибирати в інтерфейсі FenixPlay.
- Розширено пошук посилань на серії у всьому HTML сторінки, включно з JSON та атрибутами поза script.
- HTTP 403 на AJAX-плейлисті AniTube не вважається виправленим. Якщо у HTML сторінки немає вбудованих посилань на серії, список серій поки не з'явиться.

**Важливо:** версія 0.2.19 опублікована для тестування. Оновлений парсер постерів і вбудований плеєр AniTube потребують перевірки на Samsung TV. Сам факт синтаксичної перевірки не підтверджує сумісність iframe, CORS або відеопотоку.

### 0.2.9 — поточна

- Переписано парсер каталогу: тепер він бере тайтли лише з `#dle-content article.story`, а не з усіх `.html`-посилань сторінки. Це має прибрати сторонні результати на кшталт «Аніме субкультура» та «Наші друзі».
- Постер тепер шукається лише всередині відповідної картки `article.story` через `span.story_post img`, без підйому до спільних батьківських блоків. Це експериментальне виправлення повторюваних/чужих постерів.
- Реалізовано запит списку серій через `engine/ajax/playlists.php?news_id=...&xfield=playlist`, який використовується бібліотекою `anitube-ua-lib` для отримання плейлиста AniTube.
- Додано розбір груп/пунктів озвучення з відповіді AJAX та резервний розбір `RalodePlayer.init(...)`, якщо AJAX-плейлист не повернув даних.
- Для прямих `.m3u8` і `.mp4` посилань додано передачу до штатного програвача Lampa; посилання FenixPlay `/vod/` продовжують оброблятися окремою гілкою.

**Важливо:** отримання плейлиста тепер реалізоване, але фактичний формат відповіді на всіх тайтлах і запуск FenixPlay ще треба перевірити на телевізорі. Сам факт знаходження серій не гарантує, що їхній відеопотік уже сумісний із програвачем Lampa.

### 0.2.8 — попередня

Перероблено екрани каталогу та деталей:
- Додано `scroll.minus()` на екранах каталогу та деталей, щоб штатний Scroll Lampa отримував висоту робочої області; це експериментальне виправлення, потрібна перевірка на телевізорі.
- Виправлено оновлення списку фокусованих елементів після асинхронного завантаження каталогу.
- Додано реєстрацію відеоджерела AniTube через `Lampa.Manifest.plugins`, щоб відкривати пошук AniTube з контекстного меню картки.
- Прибрано кнопку відкриття сторінки через вбудований браузер Lampa, якого немає у збірці користувача.
- Додано спробу розібрати посилання FenixPlay, отримати дані серії через playback API, показати вибір озвучення та передати HLS-посилання штатному `Lampa.Player.play()`.
- Уточнено повідомлення про відсутність `/vod/`: воно більше не стверджує, що посилань немає на сайті взагалі, лише що їх не знайдено у завантаженому HTML.

**Важливо:** інтеграція FenixPlay поки експериментальна. У HAR підтверджено, що API серії вимагає тимчасовий заголовок `X-Fenix-Playback`, а медіаплейлисти використовують окремий короткоживучий токен доступу. Автоматичне отримання всіх потрібних токенів і сумісність окремих HLS-аудіо/відеопотоків зі штатним програвачем ще не підтверджені. Потрібен тест на телевізорі.

## Перевірка

Версія 0.2.19 опублікована для тестування. Каталог, фільтрація карток, постери та отримання списку серій через AJAX поки не підтверджені на реальному телевізорі. Отримання токенів FenixPlay і сумісність потоків також залишаються експериментальними. HTTP 200 означає лише, що Lampa отримала JavaScript-файл; це не підтверджує роботу каталогу, токенів або відтворення.

## Про розробку

Проєкт створюється за допомогою ChatGPT (OpenAI), який виступає технічним помічником у розробці та відповідає за написання програмного коду. В основі проєкту — ідея та бачення його автора, а також прагнення зробити перегляд аніме зручнішим для української аудиторії.
