Експериментальна версія 0.2.7

AniTube для Lampa

Плагін додає каталог AniTube до меню Lampa, пошук за назвою та екран деталей тайтлу. Інтеграція з програвачем FenixPlay залишається експериментальною.

Адреса плагіна для встановлення:

https://romanlychov.github.io/anitube-lampa/anitube-lampa.js

У Lampa відкрийте Налаштування → Розширення → Додати плагін, вставте адресу вище та перезапустіть Lampa.

Відкрити файл плагіна · Вихідний код на GitHub

Це експериментальна інтеграція. Роботу прокручування, навігації пультом і відтворення потрібно перевіряти на телевізорі. Для кожного тайтлу може знадобитися окрема логіка отримання списку серій і посилань FenixPlay.
